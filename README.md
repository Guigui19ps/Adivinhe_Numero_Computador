# Adivinhe o Número

Um jogo desenvolvido em Python onde o computador tenta adivinhar o número que o jogador está pensando.

## Como funciona

O jogador pensa em um número entre 1 e 100.

O computador faz um chute e o jogador informa se o número pensado é:

- maior
- menor
- igual

O computador utiliza essas respostas para ajustar seus próximos chutes até encontrar o número.

## Tecnologias utilizadas

- Python

## Objetivo

Projeto desenvolvido para praticar lógica de programação, estruturas de repetição, condicionais, funções e variáveis em Python.
